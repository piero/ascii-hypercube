# ascii-hypercube

A terminal screensaver: a 4D hypercube (tesseract) rotating through several 4D planes,
projected to ASCII with depth-shaded edges. Pure Python 3, no dependencies.

```sh
./hypercube.py                 # or: python3 hypercube.py
./hypercube.py --speed 2       # spin faster
./hypercube.py --fps 60 --no-color
```

Press any key (or Ctrl-C) to exit. Resizing the terminal is handled live.

Tip: alias it, e.g. `alias tesseract=~/code/ascii-hypercube/hypercube.py`.
